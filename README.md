# Pyrex Glass Canvas App

A sleek, glassmorphic web application featuring draggable, transparent Pyrex-style canvas panes set against a rippled, fluid background. This single-file application allows users to create, arrange, and paint on thick glass slabs, edit embedded text, and generate AI-driven multimedia content—all within a highly polished, visionOS-inspired interface.

## 🪟 Features

*   **Thick Glass Aesthetics:** High-fidelity glassmorphism with heavy, clear slab edges, light refraction, and deep inset shadows.
*   **Draggable Canvas Panes:** Spawn multiple rounded Pyrex glass panes with dedicated drag handles to easily arrange your workspace.
*   **Drawing & Painting:** Integrated HTML5 canvas on every pane with a neon color picker for sketching and annotating.
*   **Direct Text Editing:** Click directly on any text inside the glass panes to edit labels, statistics, and titles on the fly.
*   **AI Text-to-Image:** Generate custom images directly onto a new glass slab using embedded text-to-image prompts.
*   **AI Animation & Audio:** Trigger 6-second animated sequences with audio, rendered seamlessly inside the glass UI.
*   **SVG Export:** Capture the exact state of your layered glass workspace and download it as a scalable vector `.svg` file.

## 🚀 Quick Start

This application is built entirely with frontend web technologies (HTML, CSS, JavaScript) and requires no build tools or package managers.

1.  Download or clone the repository.
2.  Save the code as `index.html`.
3.  Double-click `index.html` to open it directly in any modern web browser (Chrome, Edge, Safari, Firefox).

## 🛠️ Usage

*   **Add Pane:** Click the **"+"** icon in the bottom glass toolbar to spawn a new drawing pane.
*   **Draw:** Select a color from the color picker in the toolbar and click/drag on any pane to draw.
*   **Move:** Click and drag the frosted pill-shaped handle at the top of any pane to reposition it.
*   **Generate AI Content:** Use the text input and action buttons in the toolbar to spawn AI images or audio/animation panes.
*   **Export:** Click the **Export SVG** button in the toolbar to download your current canvas layout.

## 🌐 Deployment

To share your app live on the web, you can use any free static hosting provider:

*   **GitHub Pages:** Push the `index.html` file to a GitHub repository and enable GitHub Pages in the repository settings.
*   **Netlify Drop:** Drag and drop the folder containing your `index.html` file into [drop.netlify.com](https://drop.netlify.com).
*   **Vercel:** Connect your GitHub repository to Vercel for automatic deployments.
